## 结论陈述
FILT 的动态几乎全部由自身对数空间的自回归惯性解释（log-AR(6)+RidgeCV，CV R²=0.696），
外生变量（ARDL）仅额外 +0.009。时滞参数在统计意义上不可辨识（CCF/MIC/TE 全 τ*=0），
但可经由三源交叉（softmax 学习/事件 CCF/工艺先验）确定物理可信值 τ=4h。
**"不可辨识"是闭环系统设计目标（出水稳定）的直接后果，不是方法缺陷**——这是
论文最强的论证材料（IN-07）。

## 数学公式
```
log(FILT(t)+1e-3) = c + Σ_{i=1..6} φ_i·log(FILT(t−i)+1e-3) + ε(t)
```
- 估计器 RidgeCV（α∈{0.001..100}，5 折均选 α=1.0）
- log 变换物理依据：乘性工艺衰减→加性误差（与 Q1 的 β₂ 递推共享"惯性是信号"结构）
