## 1. 架构概览

Q3 不再使用原计划的 TCN→GRU + N-BEATS + RF 元学习器（设计于 Q1/Q2 之前），改为 **两步链式推理**，全部组件均为 Q1/Q2 已验证模型：

```
2026年2月数据（12行/月）
       ↓
Step 1 — FILT 序列重建
   ├─ Feb 1: 直接取 FILT + 1h 样条插值
   └─ Feb 10/20: AR(6) 滚动预测 + 2025同期融合 + 1h 插值
       ↓
Step 2 — CSTR 1h 递推预测
   NTU(t) = β₂(t)·NTU(t-1) + (1-β₂(t))·FILT(t)
   β₂(t) = exp(-Δt·Q(t-1) / (A_tier·H(t-1)))
       ↓
Step 3 — Sobol 全局敏感性
   Saltelli 采样 → 一阶 S_i + 总阶 S_Ti → 敏感度排序
```

## 2. FILT 重建算法

### 2.1 Feb 1（FILT 有值）

```
原始 FILT（12点×2h, TIME=700-500）
    ↓
三次样条插值 → 1h 分辨率（13点, 7:00-19:00）
    ↓
物理约束: FILT≥0, |ΔFILT|≤0.5/步
```

### 2.2 Feb 10/20（FILT 缺失）

**Stage A — AR(6) 2h 精度滚动**

从最近已知 FILT 值往后滚动预测：
```
log_FILT(t) = φ₁·log_FILT(t-1) + ... + φ₆·log_FILT(t-6)
FILT(t) = exp(log_FILT(t)) - ε
```

**Stage B — 2025 同期融合**

取 2025年同日同时间段 FILT 作为历史基线：
```
α = exp(-||C_2026 - C_2025||² / 2σ²)    ← RBF 相似度
FILT_fused(t) = α·FILT_2025(t) + (1-α)·FILT_AR(t)
```

其中 C 为环境上下文向量 [RW_NTU₀, TW_FLOW₀, CW_WELL₀, RIVER_LEVEL₀] 目标日前最近时间点。

**Stage C — 1h 降尺度**

三次样条插值 + 物理约束 → 1h 分辨率。

## 3. CSTR 1h 递推预测

### 3.1 步长转换

| 参数 | 2h (Q1) | 1h (Q3) |
|:----:|:-------:|:-------:|
| β₂ | exp(-2/θ) | exp(-1/θ) = β₂_Q1^0.5 |
| θ | A·H / Q | 同左 |

### 3.2 递推公式

```
t = t₀+1 → 19:00:
  tier   = classify(FILT(t))
  β₂(t)  = exp(-1 · Q(t-1) / (A_tier[tier] · H(t-1)))
  NTU_raw = β₂(t)·NTU(t-1) + (1-β₂(t))·FILT(t)
  NTU(t)  = clip(NTU_raw, 0, FILT(t)+0.05)
  NTU(t)  = enforce_smooth(NTU(t), NTU(t-1), max_step=0.20)
```

### 3.3 初始 NTU

```
Feb 1: NTU₀ = Jan 2026 月均值（~0.18）
Feb 10: NTU₀ = 2025年2月10日同期最后已知 NTU
Feb 20: NTU₀ = 2025年2月20日同期最后已知 NTU
```

## 4. Sobol 全局敏感性

### 4.1 分析变量

| # | 变量 | 分布 |
|:-:|:----:|:----:|
| 1 | FILT_1h | 2025 经验分布 |
| 2 | η_coag | 混凝去除效率 |
| 3 | TW_FLOW | 出厂流量 |
| 4 | CW_WELL_LEVEL | 清水池水位 |
| 5 | RW_NTU | 原水浊度 |

### 4.2 采样

Saltelli 方案, N=1024, D=5:
```
总采样数 = N × (2D+2) = 1024 × 12 = 12288
```

### 4.3 输出

- 一阶效应 S_i（柱状图）
- 总阶效应 S_Ti（柱状图）
- 交互效应 S_Ti - S_i（热力图）

## 5. Q1 与 Q3 的预测关系

| 维度 | Q1 预测 | Q3 预测 |
|:----:|:-------:|:-------:|
| 模型 | 同 CSTR 段2 | 同 CSTR 段2 |
