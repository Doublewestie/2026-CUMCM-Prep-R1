## 平衡检测器的物理根源

RL (河流水位) 和 Q (出厂流量) 的乘积正负反映了清池是否处于水力均衡态。同向时全池参与混合 (A=100)，反向时死区扩大/短流加剧 (A=20)。系统 67% 时间处于失配态——这是清池行为不可忽略的复杂度。

## 最终公式

NTU(t) = β₂·NTU(t-1) + (1-β₂)·FILT(t), β₂ = exp(-2h/θ), θ = A·CW/Q

```
A = 400  if FILT ≤ 0.05
  = 250  if 0.05 < FILT ≤ 0.15
  = 100  if FILT > 0.15 and (RL-6.09)*(Q-44.0) > 0
  = 20   if FILT > 0.15 and (RL-6.09)*(Q-44.0) ≤ 0
```
