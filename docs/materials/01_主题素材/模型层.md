## 结论陈述
出厂水浊度 NTU 由清水池混合动力学主导，可精确描述为单级 CSTR 的离散化状态方程：
NTU(t)=β₂·NTU(t-1)+(1-β₂)·FILT(t)。状态变量必须是 NTU（不可用于 FILT，后者是滤池
AR 过程）。等效底面积 A 非固定常数，而是 tier 依赖（400/250/30）+ 水力均衡态调制
（Balance Detector：100/20）。全量 in-sample R²=0.807，诚实 5 折 TS-CV=0.737；
对比原 XGBoost 黑箱 0.34 提升 +0.47。

## 数学公式（论文核心公式之一）
```
NTU(t) = β₂(t)·NTU(t-1) + [1−β₂(t)]·FILT(t)
β₂(t) = exp(−2h/θ(t))，θ(t) = A_eff·CW_WELL(t−1)/TW_FLOW(t−1)
A_eff = 400 (FILT≤0.05)；250 (0.05<FILT≤0.15)；100 ((RL−6.09)(Q−44)>0)；20 (otherwise)
```
推导：CSTR 质量守恒 V·dN/dt = Q(F−N) → 离散化（Δt=2h）；θ=V/Q=A·H/Q（用上一时刻水力状态防同期泄露）。
