# Sum 11: Q3 四层条件路由 — 方法论分析

> Agent 认知重建：Q3 探索的完整方法论记录 | 2026-07-26

---

## 一、问题定位

Q3 任务：预测 7:00-19:00 每小时 NTU。核心难点：
1. **多步递归**：CSTR 每步微小误差在 7 步内放大
2. **冷启动**：NTU(7:00) 未知，CSTR 链需要准确的初始值
3. **条件依赖性**：CSTR 的有效性随 FILT 水平、季节、水力状态变化

---

## 二、探索历程与失败模式分类

### 类型 A：ML 模型复杂度 vs 数据量不匹配

| 尝试 | 方法 | 结果 | 根因 |
|------|------|:---:|------|
| Per-fold RF | 每折 120 棵树 × 13 特征 | R²=0.195 | Fold 0 仅 119 个训练样本 |
| RF+XGB+Ridge 集成 | 三模型等权 | R²=0.251 | 多模型微幅提升 |
| per-type RF | T1/T2/T3 各自 RF | R²=0.120 | 数据量剧减 |

**教训**：Q3 样本量不足以支撑复杂 ML 模型。Q1 成功的关键是 **1-2 参数物理公式**，不是 XGBoost/RF。

### 类型 B：物理特征注入无增益（闭环掩蔽）

| 尝试 | 特征 | 结果 |
|------|------|:---:|
| η_coag 注入 | η, Δη, lag1/3, dual mode | dR²=+0.004 |
| 方向不对称 | direction, ΔFILT | dR²=0.000 |
| 总负荷 | loading (RW×Q) | dR²=0.000 |
| 矾充足度 | φ_alum | dR²=0.000 |

**结论**：闭环掩蔽效应在 Q3 全域成立——所有外部物理信号的预测价值被系统性消除。这与 Q2 的五重证据链一脉相承。

### 类型 C：成功的方法论迁移

| Q1 做法 | Q3 对应 |
|------|------|
| 按 FILT 阈值分 T1/T2/T3 | 按 FILT + NTU 趋势分 A/B/C/C_strong/C_weak |
| T1 不用 CSTR（经验采样） | A 型不用 CSTR（持久） |
| T2 压缩 CSTR（对数） | C_weak 阻尼 CSTR（γ=0.25） |
| T3 全信 CSTR | C_strong 全信 CSTR |
| Balance Detector 分 T3 | C_th=1.0 分 C_strong/C_weak |
| 全局扫描 A 参数 | 全局扫描 α, γ, C_th |

## 三、核心方法论贡献

### 3.1 CSTR 阻尼因子 γ

发现：在 FILT [0.15, 1.0) 区间，CSTR 的方向预测正确但幅度过大（NTU 实际变化 < CSTR 预测变化）。通过引入 γ 阻尼缩放偏离持久基线的幅度：

```
NTU = NTU_5am + γ × (CSTR_pred - NTU_5am)
```

γ 扫描全局最优值 0.25。物理含义：CSTR 在此区间只能提供 25% 权重，75% 锚定持久基线。

### 3.2 CSTR 适用阈值重新校准

原始阈值 C_th=0.5 来自 Q1 的 T3 判断（FILT>0.15 即适用 CSTR）。但在 Q3 多步预测中，扫描发现 C_th=1.0 才是最优：

| C_th | CV R² | 含义 |
|:---:|:---:|------|
| 0.5 | 0.576 | 太多低-FILT 天误用 CSTR |
| 1.0 | 0.586 | FILT≥1.0 的强耦合天适用 CSTR |
| 1.5 | 0.583 | 样本量太少 |

### 3.3 天型分类器设计

```python
if FILT(5am) < 0.05 and abs(NTU_5am - NTU_1am) < 0.02: return "A"
elif FILT(5am) >= 0.15 or abs(NTU_5am - NTU_1am) >= 0.05: return "C"
else: return "B"
```

A 型（49% 样本）对应 Q1 的 T1——物理信号不可用，退回持久。
C 型（22%）被进一步分为 C_strong/C_weak。

## 四、设计原则

1. **Q1 方法论完全可以迁移到 Q3**——全局参数扫描 + 条件分层 + 纯 CV 验证
2. **为 Q3 单独训练的 RF/XGBoost 全部不可行**——数据量不足是硬约束
3. **CSTR 公式的多步有效性由物理耦合强度决定**——r(FILT,NTU) 是上限
4. **γ 阻尼是 Q1 "对数压缩" 的推广**——压缩过度信号而非抹杀
5. **Fold 间的 R² 差异不是模型缺陷**——是季节性耦合强度差异的自然表现
6. **NTU(1:00) 作为 CSTR 初始化是合法的**——已知测量值，不涉及未来信息

## 五、与顶刊方法的对照

| 方法 | 适用吗？ | 为什么不适用 |
|------|:---:|------|
| TCN 时序卷积 | ❌ | Q2 验证：TCN R²=-0.15，7 参数 AR(6) 碾压 |
| N-BEATS 季节分解 | ❌ | 无多变量特征，TimesFM 零样本 R²~0 |
| GRU/LSTM | ❌ | 4375 样本不足以训练，闭环掩蔽无外部因果信号 |
| RF/CatBoost 元学习 | ❌ | per-fold 训练数据不足，每折只有 60-120 天 |
| CSTR 物理公式 | ✅ | 最优信号提取器，Q1 验证单步 R²=0.807 |
