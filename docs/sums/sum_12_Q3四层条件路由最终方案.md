## 1. 问题起点

Q3 要求预测 7:00-19:00 逐小时 NTU，给定 1:00-5:00 的已知传感器数据。原 specification 设计为双源架构（Source A: TCN→GRU + Source B: N-BEATS/TimesFM + RF 元学习器），在实施中被大幅简化。

队友第一版提交的 physical RF（step3.1）报告 R²=0.404，但评估方法存在信息泄露（RF 在全体 2025 数据上预训练后再 per-fold 验证）。严格 honest CV 下 baseline 仅 R²=0.195。

## 3. 最终模型结构

### 四层条件路由

```
预测日 5:00 → 分类
  ├─ Type A (稳态: FILT<0.05, |ΔNTU|<0.02)
  │   └─ NTU(h) = NTU(5:00)                          [0 params]
  │
  ├─ Type B (过渡: 其余)
  │   └─ NTU(h) = 0.34·CSTR(h) + 0.66·NTU(5:00)    [1 param: α]
  │
  └─ Type C (动态: FILT≥0.15 或 |ΔNTU|≥0.05)
      ├─ C_strong (FILT≥1.0)
      │   └─ NTU(h) = CSTR(h)                        [0 params]
      └─ C_weak (FILT 0.15~1.0)
          └─ NTU(h) = NTU(5:00) + 0.25·(CSTR(h)-NTU(5:00))  [1 param: γ]
```

### CSTR 链

```
cs[0] = NTU(1:00)  (已知测量值)
cs[i] = β₂·cs[i-1] + (1-β₂)·FILT(h),  i=1..6
β₂ = exp(-2h/θ),  θ = A·CW/Q
A = {400(T1), 250(T2), 100(T3+Balance), 20(T3+Mismatch)}
```

### 全局参数（固定值）

| 参数 | 值 | 含义 |
|---|---|---|
| α_B | 0.34 | Type B 中 CSTR 权重 |
| γ_W | 0.25 | C_weak 中 CSTR 阻尼因子 |
| C_th | 1.0 | CSTR 适用阈值 |
| RL_med | 8.0 | Balance Detector RL 阈值 |
| Q_med | 48.0 | Balance Detector Q 阈值 |

## 5. 核心发现

### 5.1 CSTR 的适用阈值不是 0.5，而是 1.0

通过全局扫描 C_th ∈ {0.3, 0.5, 0.7, 1.0, 1.5, 2.0, 3.0}，确定 FILT ≥ 1.0 才是 CSTR 可靠工作的物理边界。C_th=0.5 时 C_weak 区 CSTR 全局 CSTR 过度反应使 R²=-0.16。

### 5.2 辩证法：C_weak 的 γ 阻尼合成

C_weak 区 (FILT 0.15-1.0) 既不是"CSTR 完全适用"也不是"零信号"——CSTR 方向正确但幅度偏大。γ=0.25 是最优阻尼因子："信 CSTR 25%的方向 + 75% 持久的锚点"。

这与 Q1 的 T2 对数压缩是同一种物理直觉——去噪不是去信号，是压缩幅度。

### 5.3 F0 的瓶颈不是模型，是信息边界

F0 (~1月-3月) R²=0.090 远低于 F2 (R²=0.890)。原因：
- F0 有大量 C_weak 天（FILT 0.15-1.0），NTU 有变化但 CSTR 不可靠
- F2 覆盖洪季（7-9月），FILT 极高，FILT-NTU 耦合 r=0.946
- 这是季节性的物理耦合强度差异，不是模型缺陷

论文中应论证："CSTR 模型在多步 NTU 预测中的理论 R² 上限由当天的物理耦合强度决定。"

### 5.4 Q1→Q3 方法论迁移的验证

Q1 的三层分区逻辑在 Q3 的迁移：
- Q1: 按 FILT 阈值分 T1/T2/T3 → 不同 A 参数
- Q3: 按 FILT 阈值 + NTU 趋势分 A/B/C_strong/C_weak → 不同预测策略
- Q1 在 T1 区放弃 CSTR（经验采样），Q3 在 A 区放弃 CSTR（持久）
- Q1 在 T2 区压缩 CSTR（对数），Q3 在 C_weak 区阻尼 CSTR（γ=0.25）

## 6. 与 Q1/Q2 的关系

| Q | R² | 性质 | CSTR 角色 |
|---|---|---|---|
| Q1 | 0.807 | 单步，FILT(t) 已知 | 主公式 |
| Q2 | 0.696 | FILT 自回归 | 不涉及 |
| Q3 | 0.602 | 多步，未来 FILT 不可知 | 核心但需条件化 |

Q3 的 0.602 低于 Q1 的 0.807，因为多步 CSTR 递归每步放大冷启动/模型误差。Q1 只需要一步——当天 FILT(t) 已知 → CSTR 一步到位。Q3 需要 7 步——每步的累积误差使 R² 降低约 0.2。
