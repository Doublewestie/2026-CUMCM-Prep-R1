# sum_11：Q3 融合策略对比与模型收敛

## 起点
两步链式预测存在三条路径：偏置CSTR、残差RF、物理嵌入RF。需确定最优组合。

## 六种融合策略对比（5折 TS-CV）
| 策略 | R2 | vs 物理RF |
|------|:--:|:--------:|
| 物理嵌入RF（单独） | 0.404 | — |
| 残差RF（单独） | 0.327 | -0.077 |
| 全局线性融合 | 0.406 | +0.002 |
| 分 tier 自适应 | 0.406 | +0.002 |
| Meta Ridge | 0.150 | -0.254 |
| Meta GBDT | 0.079 | -0.325 |

## 关键发现
- 两模型误差相关 rho=0.96，信息几乎完全重叠
- 物理RF的 CSTR_pred 占特征重要性 64.4%
- 无论怎么融合，R2 上限就是 ~0.406

## 收敛结果
- 移除残差RF、Ridge直接模型、融合CV代码
- 最终管线：CSTR递归（偏置表）→ 物理嵌入RF → NTU 预测
- 5折 CV R2=0.404，作为 Q3 多步预测精度报告值
