## 数学公式
```
S_risk(t) = w₁·f₁(t) + w₂·f₂(t) + w₃·f₃(t)     （熵权 wᵢ 客观定权）
f₁ = 分区归一化 NTU 超标度（θ=0.15 分区）
f₂ = 连续超标时长 × β₂ 惯性折扣（Q1）
f₃ = τ 对齐差分趋势 + η_coag 加权（Q2/Q1）
分级: 舒适区/应力区分区独立 Jenks → 统一四级 {1,2,3,4}
```
