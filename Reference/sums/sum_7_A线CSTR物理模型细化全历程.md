# Sum 7: A 线 CSTR 物理模型细化全历程

> 从单参数 A=141.3 到分 tier A 三参数的范式演进 | 2026-07-25

---

## 1. 起点：单参数 CSTR, R²=0.7272

### 1.1 原始公式

清池混合效应由连续搅拌釜描述，单一自由参数 A（等效面积）控制全部动力学：

```
theta(t) = A * CW_WELL_LEVEL(t-1) / TW_FLOW(t-1)
beta2(t) = exp(-2h / theta(t))
NTU(t)   = beta2 * NTU(t-1) + (1-beta2) * FILT(t)
```

标定结果：A=141.3, 全量 R²=0.7272, 5 折 CV R²=0.7318。

### 1.2 从 R² 看出来的问题

分 tier 评估发现 R² 不均：

| Tier | FILT 范围 | 样本 | R² |
|---|---|---|---|
| T1 | <= 0.05 | 2143 (49%) | 0.862 |
| T2 | 0.05-0.15 | 1311 (30%) | 0.757 |
| T3 | > 0.15 | 921 (21%) | 0.668 |

T3 区（物理信号最强，FILT->NTU r=0.81）R² 反而最低——反直觉。这提示 A 值不适合 T3。

---

## 2. 探索路径

### 2.1 N-CSTR 串联 (step1.6) — 无效

**假设**：真实清池存在死区和短流，非理想混合可用 N 个等体积子池串联逼近。

**修正后的正确公式**：per-stage beta = exp(-N * 2h / theta) = beta2^N

**结果**：

| N | 全量 R² | T3 R² | ext R² |
|---|---|---|---|
| 1 (基线) | 0.7272 | 0.6681 | 0.5749 |
| 2 | 0.7090 | 0.6773 | 0.5887 |
| 3 | 0.6802 | 0.6821 | 0.6006 |
| 5 | 0.6074 | 0.6783 | 0.6143 |

全量 R² 随 N 增大持续下降。T3/ext 在 N=2-5 略有改善，但全量被 T1/T2 拖垮。

**根因**：真池混合行为接近单级 CSTR，多级串联的 S 型响应曲线在数据上无法找到对应。

**早期错误记录**：第一版 beta 公式写成 exp(-2h/(N*theta)) 而非 exp(-N*2h/theta)，导致 beta 向 1 偏移而非向 0 偏移。修正后数值正确但仍无实质改善。

### 2.2 运输延迟 delta (step1.6) — 有害

遍历 delta ∈ {0, 1, 2} 步（对应 0h, 2h, 4h 延迟），将 FILT(t-delta) 代替 FILT(t) 输入 CSTR。delta>0 全线降低 R²，2h 采样不能分辨滤池到清池的传输延迟。

### 2.3 管壁释放 C_base (step1.6) — 可忽略

在流量上升沿叠加 C_base * max(0, dQ/Q) 以模拟沉积物搅动。C_base 从 0 到 0.10 仅带来 R² +0.0005 的边际增益，非主要误差源。

### 2.4 变面积 k_A (step1.6) — 边际有效

A_eff = A0 * max(0.2, 1 - k_A * Q/Q_max)，k_A=0.20 给出 R²=0.7331 (+0.006)。方向对——高流量时等效面积缩小——但量级太小。

---

## 3. 关键转折：分 tier 扫 A

### 3.1 发现

在 T1/T2/T3 内各自独立扫描最优 A（k_Fr=0）：

| Tier | 最优 A | 对应的 R² (本 tier) | 对比 A=141.3 |
|---|---|---|---|
| T1 | 400 (或更大) | 0.887 | 0.862 |
| T2 | 250 | 0.760 | 0.757 |
| T3 | 30 | 0.750 | 0.668 |

A 从 T1 的 400+ 一直降到 T3 的 30 ——差了 13 倍以上。这不是噪声或误差，是**清池在不同水质/流量条件下行为有本质不同**。

### 3.2 T3 内部子区间的 U 形 R² 曲线

| 子区间 | n | 独立最优 A | R² |
|---|---|---|---|
| 0.15-0.3 | 403 | 70 | 0.666 |
| 0.3-0.5 | 220 | 100 | **0.340** |
| 0.5-1.0 | 153 | 30 | **0.338** |
| >1.0 | 145 | 30 | 0.590 |

0.3-1.0 是"崩溃区"——即使配各自最优 A，R² 仍仅 0.34。两端（0.15-0.3 和 >1.0）反倒可用。这不是参数调参问题。

### 3.3 物理根因

清池在水力学上存在两种运行模式：

- **正常模式**（低浊度，FILT<0.15）：水流近似活塞流，全池参与交换，有效面积 A≈400+
- **危机模式**（高浊度，FILT>1.0）：水厂可能启动额外泵/切换配水策略，清池接近直通管，有效面积骤降至 A≈30
- **过渡模式**（0.3-1.0）：系统在上述两种模式间切换。同一 FILT=0.4 的点，此刻可能在正常模式（A 大），彼刻可能在危机模式（A 小）。单公式无法同时适配。

## 4. Froude 死区方案 (step1.7)

### 4.1 流体力学驱动

采用 Froude 数（惯性力/重力比）驱动死区效应——Fr 大 → 短流 → A 有效缩小：

```
A_eff = A0 / (1 + k_Fr * Q / H^(3/2))
```

### 4.2 结果

最优 A0=100, k_Fr=0.03，R²=0.7437 (+0.0164 vs 基线)。

| 指标 | 基线 | Fr 方案 |
|---|---|---|
| 全量 | 0.7272 | 0.7437 |
| T1 | 0.8617 | 0.7955 |
| T3 | 0.6681 | 0.7099 |
| ext | 0.5749 | 0.6325 |

T3 和 ext 有显著提升（+0.042, +0.058），但 T1 反向下降（-0.066）。原因是单一 A0 必须在"大池慢换（T1）"和"小池快排（T3）"之间折中。

### 4.3 关键发现：Fr 收益被分 tier A 吸收

当引入分 tier A 后，所有 k_Fr>0 的组合都劣于 k_Fr=0。40 组联合扫（A1 × A3 × k_Fr）证实 Fr 调制在分 tier 框架下无边际收益——**tier 之间的切换效应远大于 tier 内 Fr 调制的效应。**

## 5. 最终方案 (step1.7+)

### 5.1 公式

```
A(t) = A1 (=400)      if FILT(t) <= 0.05
       A2 (=250)      if 0.05 < FILT(t) <= 0.15
       A3 (=30)        if FILT(t) > 0.15

theta(t) = A(t) * CW_WELL_LEVEL(t-1) / TW_FLOW(t-1)
beta2(t) = exp(-2h / theta(t))
NTU(t)   = beta2 * NTU(t-1) + (1-beta2) * FILT(t)
```

### 5.2 性能

| 指标 | 基线 (A=141.3) | 最终 (A1=400, A2=250, A3=30) | 变化 |
|---|---|---|---|
| 全量 R² | 0.7272 | **0.7827** | +0.0555 |
| T1 R² | 0.8617 | **0.8872** | +0.0255 |
| T2 R² | 0.7565 | **0.7604** | +0.0039 |
| T3 R² | 0.6681 | **0.7499** | +0.0818 |
| ext (>0.5) R² | 0.5749 | **0.7059** | +0.1310 |

参数仅从 1 个增加到 3 个，全量 R² 提升 7.7%，T3 提升 12.2%，ext 提升 22.8%。

## 6. 0.3-0.5 崩溃区专项诊断

### 6.1 残差相关阵

在 0.3-0.5 区 220 条样本上：
- **r(resid, NTU_true) = 0.755**：残差最强相关是目标值本身——均值回归
- r(resid, delta_FILT) = 0.179：FILT 突变时残差增大
- r(resid, ALUM) = 0.168：操作员投药与残差同步

### 6.2 方向不对称

| 状态 | n | R² | bias |
|---|---|---|---|
| FILT 上升 | 111 | 0.375 | +0.083（欠估） |
| FILT 下降 | 69 | 0.357 | -0.016（近零） |

上升沿模型滞后于真实，下降沿基本不偏。滞回不对称。

### 6.3 加速度项

NTU(t) = CSTR(t) + gamma * (FILT(t) - FILT(t-1))。在 0.3-0.5 区 gamma=0.20 时增益 +0.020，在 T3 全量增益 +0.028。但全量仅在 gamma=0.05 时增益 +0.0007，不足以引入新参数。

### 6.4 结论

0.3-0.5 崩溃区不是参数问题。该区域横跨正常模式与危机模式的切换走廊，系统状态非二元——同一 FILT=0.4 的样本可能处于两种截然不同的流体力学状态。单公式必然在此两不靠。这是 CSTR 框架的已知局限，不是待修复的 bug。

## 7. 方法论教训

| 教训 | 来源 | 适用 |
|---|---|---|
| **分 tier 扫参揭示隐藏的系统异质性** | 当全量最优 A=141.3 在 T1 被证明需 400+、T3 被证明需 30 时，暴露了全局参数的伪装 | 所有回归场景 |
| **全局最优可能是各子群不佳的折中** | A=141.3 对 T1 太大、对 T3 太小，对谁都不是最优——但在全量上它是 MSE 最小点 | 多模态数据 |
| **物理公式的参数仅在有物理依据时才应全局化** | A 在概念上是池体几何常数，应全局统一；但实际上 A 的有效值随流态变化——物理依据存在时，分 tier 反而是更诚实的建模 | 灰箱建模 |
| **"无效尝试"为论文提供叙事和讨论深度** | N-CSTR、运输延迟、管壁释放都失败——但这证明了单级 CSTR 的适定性、管道延迟在 2h 尺度下不可辨识、沉积物释放非主要机制。每一步失败都排除一个备选假说 | 论文讨论 |
| **Froude 数提供了正确的物理直觉但分 tier 提供了实现** | Fr 驱动的死区效应在流体力学上正确，但其效应在数值上完全被分 tier A 吸收——物理机制通过更简单的参数化实现了 | 建模效率 |
