# 素材卡 6-1：方法学 — 闭环掩蔽效应（论文核心论点）【实证/推断】

## 结论陈述
闭环控制的饮用水处理系统（操作员按 FILT 反向调节 ALUM + 99.7% 去除率）会**主动消除
外部因果信号**，使"物理诊断信号在预测层面不可利用"成为系统结构属性而非模型缺陷。
七重独立证据（统计/物理/学习/诊断/结构/NN×2）共同支撑。系统的设计目标（出水稳定）
恰好等于"信号可检测性为零"——**识别"不可识别"本身就是学术发现**。
